WHY THE CURRENT AESTHETICS NEED IMPROVEMENT
==================================================

The existing GUI works, but visually it currently feels like an internal developer/engineering tool rather than finished consumer desktop software.

The problem is NOT simply the dark navy colour scheme.

The navy/turquoise Jenga Video Studio identity can remain.

The main problems are:

1. WEAK VISUAL HIERARCHY

Almost every control has similar visual importance.

Major actions, secondary actions, configuration controls and technical information all compete for attention.

The user's eye should immediately understand:

- where they are
- what they need to do
- what the application is currently doing
- what the primary action is
- what can safely be ignored

2. TOO MANY LARGE RECTANGULAR CONTROLS

There are many full-width buttons, text boxes and panels.

This makes the interface feel like a configuration form rather than creative video software.

Use better spacing, grouping, cards, smaller secondary buttons and clear primary actions.

3. EXCESSIVE EMPTY SPACE

Some screens contain very large empty panels.

For example, the Production screen has a huge amount of unused space while the actual production status occupies relatively little of the window.

Use this space intelligently for progress information, scene previews and production activity.

4. SETUP IS TOO TECHNICAL

The current Setup screen exposes concepts such as:

- Ollama
- Qwen model names
- FFmpeg
- Python
- Piper
- ComfyUI
- workflow files
- OAuth

These are useful for development and advanced configuration, but a normal customer should not need to understand the underlying technology.

The normal Setup experience should communicate:

Local AI            Ready / Needs setup
Video Engine        Ready / Needs setup
Narration           Ready / Needs setup
Image Generation    Optional / Ready
Video Generation    Optional / Ready
YouTube             Connected / Not connected

Provide one obvious action such as:

INSTALL / REPAIR COMPONENTS

Keep the existing detailed configuration available under:

Advanced Setup

DO NOT DELETE the advanced functionality.

Simply move technical controls away from the normal consumer-facing experience.

5. REVIEW CURRENTLY LOOKS LIKE A FORM

The Review screen should feel like a lightweight video editor.

The existing large video preview is appropriate.

Redesign the surrounding interface so that it contains:

- prominent video preview
- playback controls
- horizontal scene/timeline strip
- selectable scene thumbnails
- scene number/duration
- properties inspector for the selected scene
- narration editor
- on-screen heading
- visual treatment
- visual prompt
- graphic labels
- regenerate visual
- save changes
- rerender video

Selecting a scene should populate the inspector with that scene's existing information.

Preserve the existing scene editing/rendering functionality.
